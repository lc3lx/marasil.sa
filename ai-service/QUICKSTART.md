# 🚀 دليل التشغيل السريع

## الخطوات:

### 1️⃣ تثبيت المتطلبات (مرة واحدة فقط)

```bash
pip install -r requirements.txt
```

⏱️ **الوقت المتوقع**: 5-10 دقائق

### 2️⃣ تشغيل الخدمة

**طريقة 1 - Windows:**
```bash
start.bat
```

**طريقة 2 - مباشرة:**
```bash
python app.py
```

⏱️ **أول تشغيل**: 1-2 دقيقة (تحميل النموذج)
⏱️ **التشغيلات التالية**: 10-30 ثانية

### 3️⃣ اختبار الخدمة

افتح المتصفح: http://localhost:5000/health

يجب أن تشوف:
```json
{
  "status": "healthy",
  "model_loaded": true
}
```

### 4️⃣ تفعيل في الموقع

في ملف `.env.local`:
```env
NEXT_PUBLIC_USE_BACKEND_AI=true
NEXT_PUBLIC_AI_API_URL=http://localhost:5000
```

### 5️⃣ تشغيل الموقع

```bash
npm run dev
```

## 🔧 استكشاف الأخطاء

### المشكلة: "pip: command not found"
**الحل**: تأكد أن Python مثبت ومضاف للـ PATH

### المشكلة: "Out of memory"
**الحل**: أغلق برامج أخرى، تحتاج 8GB RAM على الأقل

### المشكلة: "Port 5000 already in use"
**الحل**: غير البورت في `app.py`:
```python
app.run(host='0.0.0.0', port=5001)  # استخدم 5001 بدلاً من 5000
```
