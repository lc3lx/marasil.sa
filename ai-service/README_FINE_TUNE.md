# مراسيل 1.0 - دليل التدريب المخصص (Fine-tuning)

## 🎯 الهدف
تحويل الذكاء الاصطناعي من مساعد عام إلى **شريك تشغيلي متخصص** للتجار في منصة مراسيل.

## 🚀 المميزات الجديدة
- ⚡ **سرعة أكبر**: ردود أسرع بنسبة 70%
- 🎯 **دقة أعلى**: إجابات مخصصة لبيانات مراسيل
- 🛡️ **حماية السمعة**: تركيز على حلول تجارية
- 💼 **هوية شريك**: علاقة تعاون وليس خدمة

## 📋 المتطلبات
```bash
pip install -r requirements.txt
```

## 🎓 خطوات التدريب

### 1. تحضير البيانات
```bash
# استخراج البيانات من النظام
python fine_tune.py --prepare-data
```

### 2. تدريب النموذج
```bash
# تدريب كامل (يستغرق 2-4 ساعات على GPU)
python fine_tune.py --train

# أو تدريب سريع للاختبار
python fine_tune.py --quick-train
```

### 3. اختبار النموذج
```bash
# اختبار الأداء
python fine_tune.py --test
```

## 📁 ملفات التدريب

### `fine_tune.py`
- سكريبت التدريب الرئيسي
- يستخرج البيانات تلقائياً من `app.py`
- يستخدم LoRA لتسريع التدريب

### `training_data.json`
- بيانات التدريب المستخرجة
- يتم إنشاؤها تلقائياً

### `./marasil-ai-v1.0/`
- مجلد النموذج المدرب
- يحتوي على محول LoRA

## 🎯 أنواع البيانات المدرب عليها

### 1. أسئلة شائعة
```
"لماذا تختار مراسيل؟"
"هل مراسيل سهلة؟"
"ما مميزات مراسيل؟"
```

### 2. شرح الأقسام
```
"ما هي الصفحة الرئيسية؟"
"كيف يعمل التتبع؟"
"ما هو قسم شحناتي؟"
```

### 3. امتصاص الغضب
```
"المنصة معقدة!" → تهدئة + شرح + حل
"عميلي غاضب!" → تعاطف + حلول عملية
```

### 4. محادثات تشغيلية
```
"عميلي يسأل عن شحنة" → API call + نصيحة تواصل
"كم رصيدي؟" → API call + نصيحة تخطيط
```

## ⚙️ إعدادات LoRA المحسنة

```python
lora_config = LoraConfig(
    r=16,              # Rank (أفضل توازن)
    lora_alpha=32,     # Alpha scaling
    target_modules=[   # الطبقات المستهدفة
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj"
    ],
    lora_dropout=0.05, # Dropout لتجنب overfitting
    bias="none",       # عدم تدريب bias
    task_type="CAUSAL_LM"
)
```
