```bash
cd d:\work\last 1\Mrasil-master
npm run dev
```

### 3. التأكد من الإعدادات
في `.env.local`:
```env

NEXT_PUBLIC_AI_API_URL=http://localhost:5000
```

## 📝 ملاحظات مهمة

1. **التوكن**: يتم أخذه تلقائياً من localStorage
2. **اسم المستخدم**: يتم أخذه من userData في localStorage
3. **الأمان**: كل طلب يستخدم التوكن للمصادقة
4. **الأداء**: النموذج يعمل على CPU (سريع ومستقر)

## 🔧 استكشاف الأخطاء

### المشكلة: "النموذج غير متوفر"
**الحل**: تأكد أن `python app.py` شغال في مجلد `ai-service`

### المشكلة: "فشل الاتصال بالخادم"
**الحل**: تأكد أن:
1. Backend AI شغال على `http://localhost:5000`
2. Frontend يشير للعنوان الصحيح في `.env.local`

### المشكلة: "فشل جلب البيانات"
**الحل**: تأكد أن:
1. المستخدم مسجل دخول (التوكن موجود)
2. API الخلفي شغال على `https://www.marasil.site/api`
